# Подборка вин: демо-приложение на Streamlit

Приложение к ДЗ-3 «Логистическая регрессия и Streamlit». Модель (`model.joblib`), порог (`config.json`) и тестовая выборка (`test.csv`) сохранены в ноутбуке. Внутри приложения модель не обучается.

## Версия Python

**Python 3.11.** Версии библиотек закреплены в `requirements.txt`: `model.joblib` сохранён в `scikit-learn==1.9.0`, в другой версии модель может не загрузиться.

## Запуск

Команды выполняются в папке, где лежит `app.py`.

**Windows (PowerShell):**

```powershell
py -3.11 -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python -m streamlit run app.py
```

**macOS / Linux:**

```bash
python3.11 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

Приложение откроется в браузере по адресу http://localhost:8501.

## Кэширование (задание 4.5)

- Модель загружает функция `load_model()` с `@st.cache_resource`.
- `test.csv` и `config.json` читают функции с `@st.cache_data`.
- Вероятности класса 1 на тестовой выборке считает `test_proba(_model, X)` с `@st.cache_data`, ROC- и PR-кривые — `test_curves(...)` с `@st.cache_data`. При движении ползунка меняется только сравнение `proba >= threshold`, `predict_proba` на тестовой выборке заново не вызывается. Подчёркивание в `_model` говорит Streamlit не хешировать модель.

**Почему для модели `st.cache_resource`.** Он хранит в кэше сам объект и отдаёт один и тот же объект всем вызовам и всем пользователям, без копирования. Файл модели читается один раз на весь сервер. Общий объект нельзя менять — и мы его не меняем: `predict_proba` модель не изменяет.

**Почему для таблиц `st.cache_data`.** Он сериализует результат (pickle) и при каждом вызове отдаёт новую копию. Для данных это безопасно: если код в одной сессии изменит свою копию таблицы, кэш и другие пользователи этого не увидят. Для модели такой кэш не подходит: каждый вызов заново собирал бы объект модели из байтов.

**Что будет, если вызвать `joblib.load` без декоратора.** Модель читалась бы с диска и распаковывалась заново при каждом перезапуске скрипта: каждый сдвиг ползунка, каждое изменение поля. Приложение реагировало бы медленнее, а у каждой сессии в памяти была бы своя копия модели.
